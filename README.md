# 🔗 API Testing with Postman

## 📌 Project Overview

QA testing project developed during the TripleTen QA Analyst Bootcamp.

The project focused on testing APIs and validating endpoints using **Postman**, with the objective of verifying whether API responses matched the expected requirements.

## 🎯 Testing Objectives

The main objectives were:

- Test API endpoints
- Send and validate HTTP requests
- Analyze API responses
- Verify HTTP status codes
- Validate response data
- Identify unexpected API behavior
- Document test results

## 🧪 Testing Activities

- Endpoint testing
- HTTP request execution
- Response validation
- Status code analysis
- Functional API testing
- Test scenario creation
- Defect identification
- Test documentation

## 🛠️ Tool Used

**Postman**

Postman was used to create and execute API requests and analyze the responses returned by the application.
